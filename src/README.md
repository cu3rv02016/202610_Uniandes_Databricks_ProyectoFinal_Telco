# Source Code

Esta carpeta contiene el código Python reutilizable del proyecto.

## Componentes

- ingestion: Procesos de ingesta de datos.
- transformations: Limpieza y transformación de datos.
- features: Ingeniería de características para Machine Learning.
- models: Entrenamiento e inferencia de modelos.

El código será utilizado por los pipelines y notebooks de Databricks.
