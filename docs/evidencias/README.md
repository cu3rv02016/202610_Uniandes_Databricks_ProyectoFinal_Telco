## Resultados principales

- 1.000 clientes procesados.
- 924 clientes activos y 76 inactivos.
- 5 clústeres generados mediante K-Means.
- Silhouette Score: 0.7375.
- Pipeline Lakeflow ejecutado exitosamente.
- Inferencia automatizada y almacenamiento en Delta Lake.
